# Store privacy declarations

Release candidate 1.0.0. These are prepared responses. Confirm the live forms and attestations as the publisher in Phase 6.

## Chrome Web Store

| Dashboard topic | Prepared response |
| --- | --- |
| Single purpose | Help players find pangrams and get individual pangram hints for seven-letter Spelling Bee word puzzles. |
| Permission justification | `storage` keeps the current letters, display mode, and individual reveals in the browser profile, so the puzzle can resume after popup closure or restart. It also retains the Reset save revision. |
| Remote code | No. Scripts, styles, icons, and the dictionary are packaged. The solver runs offline. |
| Data usage | Recommend leaving publisher-collection categories unselected for this build after confirming the live definition of collection. The publisher receives no puzzle, reveal, preference, activity, or device data through the extension. The current puzzle and the user's choices are processed and saved only in local extension storage and are disclosed in the dedicated policy. |
| Certifications | The implementation does not sell or transfer user data to third parties, use or transfer it for purposes unrelated to the extension's single purpose, or use it for lending or creditworthiness. Read and confirm the dashboard’s current User Data Policy certifications as publisher. |
| Privacy policy | Enter the public URL after the owner publishes and verifies the extension-specific policy. |
| External navigation | A deliberate click on the footer link opens the fixed homepage in a new tab with no puzzle data, tracking parameters, referrer, or opener. The website has separate privacy practices. |

[Chrome privacy dashboard](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy) · [User Data FAQ](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)
