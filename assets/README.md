The action and management icons reuse the same bee, centered on a dark cocoa hexagon with a honey-yellow rim. The derivative uses local compositing and high-quality resampling. The checked-in PNGs are 16, 32, 48 and 128 px. The build copies them alongside the header mascot into `icons/`. Phase 5 will confirm store artwork dimensions and prepare listing assets.
