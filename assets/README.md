# Artwork and icons

The direction is a compact cream, white, and honey-yellow popup with a smiling honeybee and the centered title **Pangram Solver**. The approved Pangram Solver concept image could not be located in the supplied materials. Use that reference when it is available and the written requirements in [the architecture](../docs/architecture.md) in the meantime.

The earlier Spelling Bee Solver mascot is a candidate for the popup. Its origin record describes owner-supplied ChatGPT-generated art and commercial authorization for that project. Confirm Pangram Solver use with the owner before importing it. Keep an approved square, transparent master with its source, permitted uses, and SHA-256. Create a recognizable Pangram Solver toolbar silhouette within the same visual family. Inspect it at small sizes and on light and dark browser themes. Keep this project's source and derivatives under `assets/bee/` and package only runtime PNGs under `icons/`. [Earlier mascot origin](https://github.com/dunedinstudio/spelling-bee-solver-extension/blob/fbde03d87244d31d0d9d48cb354e1e4efb044b48/assets/bee/ORIGIN.md)

Prepare 16 and 32 px action PNGs for toolbar scale, a 48 px management-page PNG, and a 128 px extension icon. Retain a high-resolution master for separate store artwork. Confirm listing image dimensions when packaging for each store.
